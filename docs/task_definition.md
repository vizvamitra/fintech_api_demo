# Financial API

A simple financial API implemented with Ruby on Rails.

## Technology Stack

* Ruby
* Ruby on Rails
* PostgreSQL
* JWT-based authentication

## Requirements

Build a minimal API-only application. The primary goal is to demonstrate clean code, sound project structure, and reasonable architectural decisions rather than feature completeness.

The API should support the following operations:

* Create a user (email is the only required attribute)
* Retrieve a user's current balance
* Update a user's balance (e.g. deposit or withdraw funds)
* Transfer funds between two users

## Additional Notes

* Provide example `curl` commands for each of the four operations above.
* Validation rules, error handling, data model design, and other implementation details are left to the developer's discretion.
* Favor a concise implementation over unnecessary complexity.
